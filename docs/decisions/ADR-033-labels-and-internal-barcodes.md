# ADR-033: طباعة الملصقات والباركود الداخلي (Phase 2 — Item 2.3)

- **التاريخ**: 2026-10-19
- **الحالة**: مقبول ومنفّذ
- **المراجع**: `docs/PLAN.md` §6 و§19، `ADR-016` (#12 و`D5`)، `docs/research/2026-10-16-comparison-market-vs-legacy-vs-new.md` (§3.10)

## السياق

أصناف كتير في محل الموبايلات (جرابات سايبة، كابلات، اسكرينات، قطع غيار، وموبايلات مستعملة) بتيجي من غير باركود مصنع مطبوع عليها، أو بتحتاج ستيكر واضح على العلبة فيه السعر والباركود أو الـ `IMEI` وتفاصيل المستعمل (`فئة A/B/C` والبطارية واللون). كما إن طابعات الملصقات الحرارية المنتشرة في السوق المصري (`Xprinter XP-235B / XP-365B` و`TSC`) بتشتغل بمقاسات ستيكر قياسية (`40×30 مم`، `50×25 مم`، `38×25 مم`، `50×30 مم`) وبتفهم لغة `TSPL / TSPL2` أو طباعة صورة عالية الدقة عشان الحروف العربي تطلع متصلة ومظبوطة.

## القرارات المعمارية

1. **الباركود الداخلي القياسي (`EAN-13` يبدأ بـ `200`) بدون أي تعديل في قاعدة البيانات**:
   - الأصناف اللي مالهاش باركود مصنع بيتولّد لها كود داخلي قياسي مكوّن من 13 رقم يبدأ بـ `200` متبوع بـ 9 أرقام تسلسلية ورقم تحقق `EAN-13 Check Digit` صحيح (`domain/catalog/shop_code.rs`: `next_shop_code`).
   - الكود الداخلي بيتحفظ في نفس عمود `products.barcode` وبيتقرأ فوراً بأي قارئ باركود USB أو كاميرا الموبايل في شاشة البيع.
   - يمكن توليد الكود الداخلي لصنف واحد (من شاشة إضافة صنف، أو تعديل صنف عبر زرار «اعمل كود للمحل»، أو شاشة الملصقات) أو دفعة واحدة لكل الأصناف اللي من غير باركود («اعمل أكواد للكل»).
2. **ترميز باركود حقيقي قابل للقراءة بالاسكانر (`EAN-13` + `Code-128B`)**:
   - الأرقام المكوّنة من 13 رقم صحيحة الـ Check Digit تُرسم بترميز `GS1 EAN-13` القياسي (95 موديول مع حراس البداية والوسط والنهاية وجداول الـ Parity `L / G / R`).
   - أرقام الـ `IMEI` (15 رقم) أو الأكواد الأخرى تُرسم بترميز `Code-128B` القياسي مع رمز التحقق `Modulo 103` وحارس النهاية.
   - هذا يضمن إن أي ملصق مطبوع من البرنامج يتقرأ فعلياً بأي قارئ باركود حقيقي في المحل.
3. **ملصقات الأصناف وملصقات علب الموبايلات (`IMEI`)**:
   - **ملصق صنف بالعدد / إكسسوار**: اسم المحل (اختياري) + اسم الصنف + خطوط الباركود (`EAN-13` أو `Code-128`) + الأرقام + سعر البيع (اختياري).
   - **ملصق وحدة `IMEI` (موبايل جديد أو مستعمل)**: اسم المحل + اسم الجهاز + سطر حالة المستعمل (`فئة A/B/C · بطارية 88% · اللون · الملحقات`) + باركود `Code-128B` لرقم الـ `IMEI` + سعر البيع.
4. **مقاسات الستيكر ومخرجات الطباعة (`PNG 2x High-DPI` + `TSPL2`)**:
   - دعم المقاسات القياسية: `40×30 مم (قياسي)`، `50×25 مم`، `38×25 مم`، و`50×30 مم (علبة)`.
   - إمكانية ملء عدد النسخ بالكمية المتاحة في المخزن بضغطة واحدة («املأ بالمتاح في المخزن»).
   - دعم الطباعة كصورة عالية الدقة (`2x High-DPI Canvas PNG`) لضمان اتصال الحروف العربي على أي طابعة، بالإضافة إلى توليد ونسخ أوامر `TSPL2` القياسية (`SIZE`, `GAP`, `DIRECTION`, `CLS`, `BARCODE`, `PRINT`).
