# جرّب البرنامج الحقيقي

> **الحالة (2026-10-17):** المرحلة 1 بدأت. الجاهز دلوقتي: الشكل الجديد بالطابعين والثيمين، وشاشة البيع (كاش وأصناف بالعدد)، والإعدادات ← الشكل. الباقي بيتبني بالترتيب في [`tasks/todo.md`](../tasks/todo.md).

## على كمبيوتر المحل (ويندوز): البرنامج نفسه

1. **التنزيل:** على GitHub افتح المستودع ← **Actions** ← آخر تشغيل علامته خضرا وفي اسمه `[windows]` ← تحت **Artifacts** نزّل `mobile-shop-system-windows-installer`. الملف بيفضل موجود 30 يوم من يوم التشغيل.
2. **التثبيت:** فك الـ zip وشغّل ملف الـ setup اللي جواه. البرنامج لسه مش موقّع، فويندوز ممكن يقول «Windows protected your PC»: اضغط **More info** وبعدين **Run anyway**. ولو الجهاز ناقصه WebView2 (نادر في ويندوز 10 و11)، المثبّت بيحمّله، وده محتاج نت مرة واحدة.
3. **أول تشغيل:** اكتب اسمك وكلمة سر (8 حروف على الأقل). ده حساب المالك.
4. **المخزن:** ضيف صنف بالاسم والسعر (والباركود لو موجود)، ونوعه «بالعدد»، وبعدين استلم له كمية. الصنف اللي مالوش سعر ما بيتباعش، والشاشة بتقول كده.
5. **البيع:** دوّر بالاسم أو امسح الباركود أو دوس على الصنف. **F2** الكمية، و**F8** «انتظار» وفاتورة جديدة، و**F12** الدفع كاش بالباقي.
6. **الإعدادات ← الشكل:** الطابع («لافتة الشارع» أو «علبة الموبايل»)، والثيم، ولون المحل (أي لون بيفضل الكلام عليه مقروء)، والخط، والحجم، والأرقام. التغيير بيطلب كلمة سر المالك، إلا الثيم: أي حد يقدر يغيّره من زرار «غامق» أو «فاتح».

> **البيانات حقيقية** ومحفوظة على الجهاز نفسه في `%LOCALAPPDATA%\com.mshop.system`. البرنامج شغال من غير نت.

## من غير تثبيت: نسخة التجربة في المتصفح

نفس الشاشات ببيانات وهمية في الذاكرة، وبتتمسح لما الصفحة تتقفل. الحسابات: بيتر (المالك)، ويوسف، ومارينا، وكلمة السر 1234 للكل.

```bash
npm ci
npm run demo        # وافتح http://localhost:5173
```
