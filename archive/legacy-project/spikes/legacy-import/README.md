# Spike (throwaway): إثبات استيراد بيانات legacy

**الحالة:** spike مؤقت لإثبات الجدوى. ليس جزءًا من تطبيق الإنتاج، وقد يُحذف أو يُستبدل
بمحوّل حقيقي بعد اعتماد مخطط قاعدة البيانات. لا يُبنى عليه شيء قبل نجاحه ومراجعته.

## لماذا هذا الـspike

خطة التنفيذ (`docs/superpowers/plans/2026-09-28-mobile-shop-system.md`، المهمة 1.4) تشترط
إثبات مسار الاستيراد **قبل** تثبيت مخطط SQLite. هذا الـspike يجيب على سؤالين حاسمين:

1. هل نستطيع قراءة تصدير legacy وتحويله إلى سجلات لقطة (snapshots) بلا اختراع بيانات؟
2. هل تظهر مجاميع التقارير القديمة مطابقة للصيغة المعتمدة في المواصفات؟

## اكتشاف حاسم: شكلان مختلطان داخل نفس القسم

`dev_extracted/dev/js/storage.js:110-138` يقرأ أقسام اليوم ويحوّل السجلات من
«شكل قاعدة البيانات» إلى «شكل محلي» عند القراءة فقط. الـmarkers المستخدمة:

| القسم | marker يدل على شكل DB |
|---|---|
| `acc` | `snapshotName` |
| `used` | `snapshotName` |
| `sw` | `snapshotName` |
| `cash` | `walletName` |
| `exp` | `snapshotCategory` |
| `phones` | `snapshotModelName` |
| `repairs` | لا يوجد mapper مسجّل → يبقى محليًا دائمًا |

النتيجة العملية: **تصدير legacy قد يحتوي السجلين معًا داخل نفس المصفوفة**، والسجل الجديد
من ADR-003 يحمل `id` بينما القديم غالبًا لا يحمله. أي محول يفترض شكلًا واحدًا لكل قسم
سيخسر بيانات. لذلك يكتشف هذا الـspike الشكل **لكل سجل على حدة**.

## ما يتحقق منه هذا الـspike (قبول)

1. لا يُنشأ `productId` من اسم حر.
2. لا يُستنتج رصيد إكسسوارات من `mshop_ca` / `mshop_cu` (بلا حقول كمية أصلًا).
3. كل معاملة بلا مستخدم تأخذ `legacy-import` بدل نسبتها لأحد.
4. لقطات الربح/الشراء/البيع تُحفظ كما هي في المصدر.
5. يُرصد كل سجل يحتاج مراجعة يدوية بدل تخمينه.
6. مجاميع التقرير القديم مطابقة للصيغة المعتمدة في المواصفات.

## التشغيل

```powershell
node spikes/legacy-import/import_probe.mjs
```

يفشل التنفيذ (exit 1) عند كسر أي شرط قبول. المتطلبات: Node فقط، بلا اعتماديات.

## الملف التجريبي

`fixtures/legacy-export-mixed.json` اصطناعي ويحتوي عن قصد:
- يومان (`2026-09-20`, `2026-09-21`).
- سجل إكسسوار بشكل DB وسجل آخر بشكل محلي **في نفس القسم**.
- معاملة ملغاة (`_rolled`)، صيانة ملغاة، مصروف، كاش، سوفت وير، بيع هاتف، وصيانة بعميل.
- كتالوج هواتف بكميات وسجل شراء، وكتالوج إكسسوارات/مستعمل **بلا كميات**.
